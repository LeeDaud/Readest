# Z-Library 访问 UI 优化 · 2026-10-14

用户已确认之前的 Z-Library 集成测试通过。本次优化网站配置、访问导航、换站提示和下载反馈，沿用 Readest 名称、上游图标与主题色。

## 行为

- 设置中改为网站列表，支持添加、编辑、删除、可选名称与上下移动，标出优先入口；保存仍使用原设置文件，兼容旧网址列表。
- Z-Library 浏览器顶部保留关闭、返回、网站名称与更多，刷新/停止在更多菜单；更多中可直接打开网站设置。
- Android 连接/换站显示当前尝试序号和入口名称；全部入口失败时提供重试与网站设置。成功换站清除失败入口历史。
- Android 下载结果置于底部，展示下载中、入库中、成功和失败。有已知文件长度时显示百分比。
- 下载失败与入库失败分别显示和重试：下载失败重新下载；入库失败复用已下载文件触发现有导入流程。缓存事件按文件名对应，避免重试其他文件。
- Z-Library 成功提示中的「立即阅读」不再八秒后消失；用户可手动关闭提示，或由新下载状态替换。
- iOS 同步名称、精简导航、底部状态、失败操作和原生设置返回协议；受环境限制未构建或实测。
