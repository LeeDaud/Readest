# 发现书籍与阅读记录改版验证

维护基线：Readest 0.12.16，功能分支 `codex/discovery-reading-v2`

最终应用源码：`8a29bec77741d95f85d985c945dea82fa3680b54`

## 已实现

- 发现页沿用 Readest 主题、页头、按钮和列表，一次展示一张卡片，自动获取资料，左滑不感兴趣可撤销
- Open Library 在线候选按主题轮换、分别分页、预取并持久化；按作品和已知别名排除重复、已读和书架已有书籍；每次请求批量大小不限制总推荐次数
- 封面缺失收起区域，评分缺失隐藏；没有资料时采用文字卡片，不显示假封面或 0 分
- 独立已读清单支持添加、编辑、可选完成日期、书架选择、搜索、删除撤销及分页；旧记录迁入独立数据库，设置中的原始记录保留作备份
- 发现入口保留在导入菜单；首页新增已读清单入口，右上角改为阅读时长
- 时长页显示总计和每本书累计，复用上游事件库；补齐前台恢复、闲置交互恢复和长时间单页阅读分段保存，普通分屏阅读仅一个实例计时
