# 发现书籍与阅读记录改版验证

维护基线：Readest 0.12.16，功能分支 `codex/discovery-reading-v2`

## 已实现

- 发现页沿用 Readest 主题、页头、按钮和列表，一次展示一张卡片，自动获取资料，左滑不感兴趣可撤销
- Open Library 在线候选按主题轮换、分别分页、预取并持久化；按作品和已知别名排除重复、已读和书架已有书籍；每次请求批量大小不限制总推荐次数
- 封面缺失收起区域，评分缺失隐藏；没有资料时采用文字卡片，不显示假封面或 0 分
- 独立已读清单支持添加、编辑、可选完成日期、书架选择、搜索、删除撤销及分页；旧记录迁入独立数据库，设置中的原始记录保留作备份
- 发现入口保留在导入菜单；首页新增已读清单入口，右上角改为阅读时长
- 时长页显示总计和每本书累计，复用上游事件库；补齐前台恢复、闲置交互恢复和长时间单页阅读分段保存，普通分屏阅读仅一个实例计时

## 本地验证

- 类型检查、改动范围 Lint 和静态 Tauri 前端构建通过，生成 `/discover`、`/read-history`、`/reading-stats`
- 9 个专项测试文件共 48 项通过，覆盖数据库迁移/删除后不复活、超过 100 本跨批次持续推荐、旧记录过滤、页面手势、独立清单编辑、下载导入、统计聚合、后台与闲置恢复
- 真实 Open Library 查询：6 次请求获取 120 个不同 Work ID，46 项有封面 ID，8 项有评分；不等同于这些书都有简介，也不等同于 Android HTTP 连通性验收
- Chromium 390×844：单卡片、自动简介、首页入口、独立清单添加编辑和重载持久化、统计数据库加载通过，无页面异常或横向溢出；截图和日志在忽略的 `.validation/discovery-v2-*`
- 全量回归首次完成：1,161 个测试文件通过，4 个跳过；13,672 项通过，16 项跳过，无失败。跳过的现有测试保留，未计入通过数
- 真实网络补测定位并修复两个问题：启动替换 AppService 包装对象导致 OPFS 重复连接，改为每窗口共享连接；封面被 COEP 拦截，改用接口支持的匿名 CORS 图片请求。两项均增加回归测试，最终代码再进行验证
